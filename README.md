# fruit-picker

Зрение для робота-сборщика фруктов. Все команды — из этой папки,
python — из виртуального окружения: `./venv/bin/python`.

## Одна камера (этап 1)

- `detect.py` — детекция фруктов (банан/яблоко/апельсин) с веб-камеры.

## Стереопара из двух обычных камер (этап 2 без RealSense)

Железо: две **одинаковые** USB-камеры, жёстко закреплённые на бруске
на расстоянии 6–12 см. После крепления не сдвигать — иначе перекалибровка.

Порядок:

1. `stereo_capture.py` — распечатать шахматную доску (ссылка в шапке файла),
   наклеить на картон, снять 20–30 пар кадров (пробел = сохранить).
2. `stereo_calibrate.py` — перед запуском вписать `SQUARE_SIZE_MM`
   (измерить клетку линейкой). Смотреть на RMS-ошибки: одиночные < 0.5 px,
   стерео < 1.0 px, база должна совпасть с линейкой.
3. `stereo_detect.py` — YOLO в обоих кадрах + триангуляция,
   в консоль и на видео выводятся X, Y, Z фрукта в мм.

Индексы камер (`LEFT_CAM`, `RIGHT_CAM`) — в шапках скриптов;
посмотреть, какие есть: `v4l2-ctl --list-devices`.

Проверка качества: положить фрукт на измеренное рулеткой расстояние
и сравнить с Z на экране. Ожидаемая точность на 1 м — порядка ±1–2 см.

## Сбор яблока в ящик (этап 3)

`pick_apple.py` — полный цикл: найти яблоко стереопарой, взять его и
сложить в ящик. Порядок движения: исходная поза -> заход СВЕРХУ к яблоку ->
сжатие клешни до контакта -> подъём -> перенос над ящиком -> разжать
(яблоко падает в ящик) -> отход вверх -> исходная поза.

Перед первым запуском снять точку сброса **рукой**, а не рулеткой:

    python arm/teach_point.py

Скрипт расслабляет суставы (клешня остаётся под напряжением и держит яблоко),
вы подводите яблоко туда, где его надо выпустить — по центру ящика, чуть выше
края, — жмёте Enter и вставляете напечатанный `RELEASE_XYZ` в `pick_apple.py`.

Почему не рулеткой: яблоко висит в клешне ниже и позади кончика (это и есть
`GRASP_OFFSET`), поэтому «край ящика плюс запас по высоте» промахивается —
яблоко выпадает заметно выше, чем ожидаешь. `teach_point.py` снимает точку той
же формулой FK, которой пользуется планировщик, так что расхождению между
системами отсчёта взяться неоткуда.

Остальное в шапке `pick_apple.py`: `CARRY_CLEARANCE_MM` — высота пролёта над
ящиком, `RETREAT_MM` — отход вверх после сброса. Если планировщик скажет, что
точка недостижима, — ящик слишком далеко (рука достаёт ~350-400 мм от основания).

## Запись эпизодов (данные для обучения)

Каждый запуск `pick_apple.py` пишет папку `episodes/ГГГГММДД_ЧЧММСС/`:
кадры обеих камер, углы суставов, точка кончика, координаты яблока,
телеметрия сервоприводов (нагрузка/ток/температура/напряжение), события
(контакт, промах) и итог эпизода.

    python episode_review.py           # список эпизодов
    python episode_review.py last      # сводка + собрать review.mp4

Подключить свой датчик: передать в `EpisodeLogger(extra_sensors=...)` функцию,
возвращающую словарь значений — они попадут в каждую запись (см. шапку
`episode_logger.py`).

## Свой датасет ягод (обучение своей модели)

Стандартная YOLO знает только банан/яблоко/апельсин. Чтобы видеть ягоды,
обучаем свою модель. Разметку ускоряет YOLO-World (ищет по тексту без обучения),
руками только правим черновик. Всё на одной камере, стереопара не нужна.

1. Список ягод — в `dataset/data.yaml` (по умолчанию strawberry/raspberry/cherry).
   Меняете `names` под свои виды. При желании — подсказки `PROMPTS` в `autolabel.py`.
2. `capture_dataset.py` — наснимать 100–300 фото на вид (разный фон, свет, ракурс).
3. `autolabel.py` — черновая разметка YOLO-World + разбивка train/val.
   Гляньте результат в `dataset/preview/`.
4. `label_tool.py` — поправить рамки руками (управление — в шапке файла).
5. Обучение:
   - локально на CPU — `train.py` (медленно, но работает; для проб уменьшите EPOCHS);
   - бесплатно на GPU — блокнот `colab_train.ipynb` в Google Colab. Датасет упаковать
     `zip -r dataset.zip dataset -x 'dataset/preview/*'`, загрузить в блокнот,
     скачать готовый `best.pt`. GPU нужен только для обучения — робот работает на CPU.
6. Подключить модель: в `stereo_detect.py` заменить
   `YOLO("yolov8n.pt")` на `YOLO("runs/detect/berries/weights/best.pt")`
   и `FRUIT_CLASSES` — на классы из `data.yaml`.

Чем больше и разнообразнее фото, тем лучше. Первый заход можно сделать
на 30–50 фото просто чтобы пройти весь путь, потом наращивать.
